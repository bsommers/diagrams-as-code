# Vector Icon Catalog

This directory contains the 59 handcrafted 24×24 resolution-independent SVG icons organized by architectural domain.

---

## Domains & Directory Structure

- [`ai/`](file:///home/bill/src/ai/diagrams-as-code/icons/ai/): Neural networks, LLMs, agents, hardware chips, vector DBs, computer vision, workflow pipelines (7 icons).
- [`business_process/`](file:///home/bill/src/ai/diagrams-as-code/icons/business_process/): Users, documents, decisions, messages, security gates, analytics (6 icons).
- [`cloud/`](file:///home/bill/src/ai/diagrams-as-code/icons/cloud/): Cloud platforms, VPCs, serverless functions, object storage, API gateways, CDNs, firewalls, DNS (8 icons).
- [`computer/`](file:///home/bill/src/ai/diagrams-as-code/icons/computer/): Workstations, laptops, mobile devices, servers, terminals, PLCs, routers, sensors (7 icons).
- [`cybersecurity/`](file:///home/bill/src/ai/diagrams-as-code/icons/cybersecurity/): Locks, keys, SOC consoles, SIEM engines, malware scanning, vaults, honeypots, shield verification (8 icons).
- [`datacenter/`](file:///home/bill/src/ai/diagrams-as-code/icons/datacenter/): Server racks, compute clusters, storage arrays, precision cooling, UPS battery backups, containers, Kubernetes (7 icons).
- [`iiot/`](file:///home/bill/src/ai/diagrams-as-code/icons/iiot/): Telemetry sensors, edge gateways, MQTT brokers, industrial PLCs, SCADA hosts, HMIs, historians, robots (8 icons).
- [`network_engineering/`](file:///home/bill/src/ai/diagrams-as-code/icons/network_engineering/): Core routers, BGP mesh, MPLS backbones, switches, HA firewalls, load balancers, patch panels, fiber optics (8 icons).
