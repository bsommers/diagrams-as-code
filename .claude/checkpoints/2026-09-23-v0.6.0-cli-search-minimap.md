## What shipped

1. **Phase 4: CLI `--interactive` Option (`ab594c5`)**:
   - Added `--interactive` (`action="store_true"`) and `--no-interactive` (`action="store_false"`) flags to `diagrams-as-code render` with tri-state `default=None`.
   - Forwarded CLI flag through `_configure()` to `Diagram.configure(interactive=...)`.
   - Batch directory rendering (`diagrams-as-code render <dir> --interactive`) exports interactive SVGs across all discovered diagram scripts.
   - Added 4 unit and integration tests in `tests/test_cli.py`.
2. **Phase 5: Client-Side Search & Node Highlighting (`401a379`)**:
   - Integrated lightweight search input field into `#svg-pan-zoom-controls` via XHTML `<foreignObject>`.
   - Client-side filtering script: real-time dynamic substring matching against node IDs and labels dims non-matching nodes to 20% opacity and non-incident edges to 15% opacity.
   - Escape key or clearing input immediately restores full element opacities and removes focus.
   - Added 2 integration tests in `tests/test_renderer_svg.py`.
3. **Phase 6: Viewport Minimap Navigator (`5119c2a`)**:
   - Integrated pinned overview minimap thumbnail widget (`#svg-minimap`) in the bottom-right corner of interactive SVG canvases.
   - Enclosed diagram content in `<g id="diagram-content">` and mirrored it in the minimap using scaled `<use href="#diagram-content">` with `#minimap-clip`.
   - Added `#minimap-viewport` rectangle dynamically tracking current visible bounds on pan, zoom, search, and reset.
   - Implemented smooth click-and-drag navigation across the minimap to pan the diagram view.
   - Added 2 integration tests in `tests/test_renderer_svg.py`.
4. **Milestone v0.6.0 Archiving & Packaging**:
   - Promoted `CAP-DIAG-CLI-INTERACTIVE`, `CAP-DIAG-SEARCH`, and `CAP-DIAG-NAVIGATOR` to `OPERATIONAL` (15 total capabilities, 15 operational).
   - Bumped package version to `0.6.0`.
   - Archived `.planning/ROADMAP.md` and `.planning/REQUIREMENTS.md` to `.planning/milestones/v0.6.0-*`.
