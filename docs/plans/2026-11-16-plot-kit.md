# Plot kit and textbook galleries

## Goal
Textbook-quality figures (calculus, algebra, differential equations, physics, finance, logic, medical, engineering/CAD) without every script hand-rolling data-to-pixel mapping, ticks and clipping.

## Scope
1. `src/diagrams_as_code/plot.py`: `Plot(diagram, x=, y=, origin=, size=)` drawing with existing primitives (paths, polygons, text). Pure stdlib, no new dependencies.
   - Frame: `grid`, `axes` (ticks, labels, log scales), `frame`.
   - Curves: `function` (asymptote/clip aware), `parametric`, `polyline`, `line`, `hline`, `vline`, `tangent`.
   - Regions: `area`, `bars` (Riemann rules), `band`.
   - Fields and ODEs: `slope_field`, `vector_field`, `trajectory` (RK4), `solve_ode`.
   - Marks and series: `dot`, `label`, `candles`, `bar_chart`.
2. Galleries built on it, ~10 figures each, in this order: `calculus_math`, `differential_equations`, `physics`, `finance`, `logic`. Medical and engineering/CAD follow as a separate phase (need extra primitives).

## Non-goals
No new runtime dependencies; no general charting library; no 3D surface plots in this phase.

## Success criteria
- Unit tests for mapping, ticks, clipping, asymptote breaks, RK4 accuracy.
- Each figure: zero `audit_gallery` defects, passes `lint`, rasterized and inspected by eye.
- Full local gate green before any push (see CLAUDE.md). No push, PR or tag without user confirmation.
