Diagrams as Code

Describe a diagram in plain Python. Get deterministic, lintable SVG, PNG and PDF. No Graphviz, no Cairo, no dependencies. Drive it from the CLI, the API, or an MCP server.

What is in the box

A drawing engine, a few focused kits, and a gallery wide enough to be a reference.

Layered engine

Shapes, groups, orthogonal routing, auto-layout and constraints. Pure standard library, enforced by import-layer tests.

Sequence diagrams

Participants, lifelines, activations, notes and loop / alt / par frames, laid out with measured text.

Gantt & timelines

Dependencies, computed critical path, milestones, a today line, and label stacking that never collides.

Plots & math

A data-space plot kit and a TeX-like typesetter: fractions, roots, binomials, accents, chemical formulas.

Draft kit

Dimension lines, hatching, leaders and organic outlines for engineering and anatomy figures.

Lint & audit

Finds lines through nodes, overlapping labels and clipped text, so a wrong diagram fails a test instead of reaching a reader.

MCP server

Render and lint from an AI client over stdio. Each script runs in a resource-limited child process.

Themes & formats

14 themes. SVG, PNG, PDF and a bill of materials from the same script.

Quickstart

Python 3.10+ and uv. Nothing else to install.

A diagram in a dozen lines
from diagrams_as_code import Diagram, Shape
from diagrams_as_code.output import render_all

def diagram():
    with Diagram("Request path", layout="auto") as d:
        web = d.add(Shape("web", "Web"))
        api = d.add(Shape("api", "API"))
        db = d.add(Shape("db", "Database", icon="database"))
        web >> d.edge("HTTPS") >> api
        api >> d.edge("SQL") >> db
    return d

render_all(diagram(), "out", "request_path")
Render, lint, serve
# render every example to SVG + BOM
uv run diagrams-as-code render examples --out build

# find visual defects (exits 1 if any)
uv run diagrams-as-code lint examples

# PNG and PDF too
uv run diagrams-as-code render examples/finance --format svg,png,pdf

# let an AI client drive it (stdio MCP)
uv run diagrams-as-code mcp --root .
