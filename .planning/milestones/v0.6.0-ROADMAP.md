# Roadmap Archive: v0.6.0

**Archived:** 2026-09-23  
**Status:** Shipped in `v0.6.0`

## Overview

Following `v0.5.0`, Milestone `v0.6.0` delivered three sequential phases: exposing `--interactive` on the CLI to allow batch generation of interactive diagrams without code edits (Phase 4), adding client-side search and node highlighting (Phase 5), and introducing a viewport minimap navigator for navigating large topologies (Phase 6).

## Phases

- [x] **Phase 4: CLI `--interactive` Option (`CAP-DIAG-CLI-INTERACTIVE`)** - Add `--interactive` flag to `diagrams-as-code render` for single-script and batch exports.
- [x] **Phase 5: Client-Side Search & Node Highlight (`CAP-DIAG-SEARCH`)** - Add HUD search filter with dynamic node matching and opacity dimming.
- [x] **Phase 6: Viewport Minimap Navigator (`CAP-DIAG-NAVIGATOR`)** - Add interactive overview thumbnail widget for large diagrams.
