# Plan: Phase 6 Plan 06-01 (Viewport Minimap Navigator)

**Phase:** Phase 6: Viewport Minimap Navigator (`CAP-DIAG-NAVIGATOR`)  
**Requirements:** `MINIMAP-01`, `MINIMAP-02`, `MINIMAP-03`  
**Goal:** Render a pinned overview minimap thumbnail widget in the bottom corner of interactive SVGs with a responsive visible bounds indicator and drag navigation.

## Context & Architecture

- `SVGRenderer` already supports interactive pan/zoom, collapsible groups, and HUD search filtering.
- When `interactive=True`:
  - Content elements (groups, edges, shapes, badges) will be enclosed in `<g id="diagram-content">`.
  - Non-interactive rendering remains completely untouched (`interactive=False` produces zero extra tags or scripts).
  - `#svg-minimap` will be rendered as a pinned HUD element at `(minimap_x, minimap_y)` in the bottom-right corner.
  - Minimap contains:
    1. Background rect `<rect class="minimap-bg" ... />`.
    2. Scaled diagram thumbnail `<g clip-path="url(#minimap-clip)"><use href="#diagram-content" ... /></g>`.
    3. Viewport rect `<rect id="minimap-viewport" ... />`.
  - Client-side script updates `#minimap-viewport` bounds dynamically during pan/zoom and enables click-and-drag navigation on the minimap.

## Proposed Changes

1. **Renderer SVG (`src/diagrams_as_code/renderer_svg.py`)**:
   - In `<defs>`: Add `<clipPath id="minimap-clip"><rect ... /></clipPath>` when `interactive=True`.
   - Wrap diagram groups, edges, and shapes in `<g id="diagram-content"> ... </g>` when `interactive=True`.
   - Add `_render_interactive_minimap(width, height)` returning `#svg-minimap` XML.
   - In `_render_interactive_script()`:
     - Add minimap pinning logic to `updateViewBox()`: compute `mx, my` based on `minimap_x, minimap_y` and apply scale transform.
     - Add `updateMinimapViewport()` calculating `vx, vy, vw, vh` from current `vb`.
     - Add `centerFromMinimap(evt)` handling click/drag on the minimap.
     - Add `mousedown`, `mousemove`, `mouseup` listeners on `#svg-minimap` to enable interactive dragging.
     - Update SVG root `mousedown` to ignore clicks within `#svg-minimap`.

2. **Integration Tests (`tests/test_renderer_svg.py`)**:
   - Add `test_interactive_svg_minimap_structure()`: verify presence of `#svg-minimap`, `#diagram-content`, `minimap-clip`, `minimap-viewport`, `<use href="#diagram-content"`, and minimap JS navigation logic.
   - Add `test_non_interactive_no_minimap()`: verify non-interactive rendering contains no minimap or diagram-content tags.

3. **Documentation (`docs/CAPABILITIES.md`, `docs/capabilities.json`, `docs/CHANGELOG.md`)**:
   - Update `CAP-DIAG-NAVIGATOR` capability status to `OPERATIONAL`.
   - Document minimap navigator in changelog.
