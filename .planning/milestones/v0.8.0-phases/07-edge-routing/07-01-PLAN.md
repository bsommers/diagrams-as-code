# Plan 07-01: Obstacle-Aware Orthogonal Routing & Multi-Rank Layout

**Phase**: Phase 7: Edge Routing & Orthogonal Waypoint Enhancements (`CAP-DIAG-ROUTER-AVOIDANCE`)  
**Status**: Ready to execute  
**Requirements**: ROUTE-01, ROUTE-02, ROUTE-03, ROUTE-04, ROUTE-05  

## Context

Edges currently route through intermediate obstacles if another node sits along the straight Manhattan midpoint path. Additionally, `LayeredLayout` only evaluates adjacent rank pairs, ignoring multi-rank crossing dynamics. This plan adds obstacle collision detection and detour routing in `OrthogonalRouter`, integrates obstacles in `layout/pipeline.py`, and extends `LayeredLayout` to penalize multi-rank edge crossings.

## Implementation Tasks

### 1. Test-Driven Development Suite (`tests/test_routing.py` & `tests/test_layered.py`)
- Test segment-box intersection logic with clearance padding.
- Test routing around a blocking obstacle situated between source and target.
- Test multi-obstacle routing and non-collision guarantees.
- Test backward compatibility: exact identical waypoints when no obstacles are specified or when path is clear.
- Test multi-rank crossing reduction in `LayeredLayout`.

### 2. Segment-Box Collision & Detour Routing (`src/diagrams_as_code/router.py`)
- Implement `_segment_intersects_rect(p1: Point, p2: Point, rect: Rect) -> bool`.
- Implement `route(self, edge: Edge, obstacles: Optional[Iterable[Rect | Element]] = None, clearance: float = 15.0) -> list[Point]`.
- Build coordinate grid from endpoints and obstacle boundaries ($\pm \text{clearance}$).
- Implement A* / BFS shortest Manhattan search with minimum bend preference.
- Retain fast-path return when direct Manhattan path is collision-free.

### 3. Multi-Rank Edge Crossings (`src/diagrams_as_code/layout/layered.py`)
- Enhance `_order()` and `_sweep()` to project intermediate rank coordinates for edges spanning $\ge 2$ ranks.
- Update `crossings()` to evaluate multi-rank edge segments between adjacent ranks.

### 4. Layout Pipeline Integration (`src/diagrams_as_code/layout/pipeline.py`)
- Pass candidate obstacle elements (`[e for e in elements if e is not edge.source and e is not edge.target]`) to `router.route(edge, obstacles=obstacles)`.
