# Plan: Phase 5 Plan 05-01 (Client-Side Search & Node Highlight)

**Phase:** Phase 5: Client-Side Search & Node Highlight (`CAP-DIAG-SEARCH`)  
**Requirements:** `SEARCH-01`, `SEARCH-02`, `SEARCH-03`  
**Goal:** Inject a lightweight search input field into the SVG interactive HUD controls with real-time client-side node highlighting and opacity dimming.

## Context & Architecture

- `SVGRenderer` generates client-side interactive SVG when `interactive=True`.
- `#svg-pan-zoom-controls` currently contains zoom-in, zoom-out, and reset buttons in the top-right corner.
- We will expand `#svg-pan-zoom-controls` to include a styled `<foreignObject>` housing an XHTML `<input id="diagram-search-input" ... />`.
- When `interactive=True`, shapes are tagged with `.diagram-node`, `data-node-id`, and `data-label`. Edges are tagged with `data-source-id` and `data-target-id`. Groups are tagged with `data-label`.
- Default non-interactive rendering (`interactive=False`) remains 100% byte-identical.

## Proposed Changes

1. **Renderer SVG (`src/diagrams_as_code/renderer_svg.py`)**:
   - In `_render_interactive_styles()`: Add styles for `#diagram-search-input`, `#diagram-search-input:focus`, `#diagram-search-input::placeholder`, and `.diagram-node, .diagram-edge, .diagram-group { transition: opacity 0.2s ease-in-out; }`.
   - In `_render_interactive_controls()`:
     - Increase HUD width to 228.0 (positioning search input on the left and zoom buttons on the right).
     - Add `<foreignObject x="4" y="3" width="126" height="24">` containing `<input xmlns="http://www.w3.org/1999/xhtml" id="diagram-search-input" ... />`.
     - Shift zoom buttons to x=134, x=165, x=196.
   - In `_render_interactive_script()`:
     - Add search filter logic (`applySearch`) listening to `input` and `keydown` (`Escape`) on `#diagram-search-input`.
     - Stop propagation on `mousedown` and `click` to prevent dragging/panning when focusing the search field.
   - In `render()`:
     - When `interactive=True`: Add `class="diagram-node"`, `data-node-id`, and `data-label` to shape `<g>`.
     - Add `data-source-id` and `data-target-id` to edge `<g class="diagram-edge">`.
     - Add `data-label` to group `<g class="diagram-group">`.

2. **Integration Tests (`tests/test_renderer_svg.py`)**:
   - Add `test_interactive_svg_search_controls()`: verify search input element, foreignObject, placeholder, and search event handling script.
   - Add `test_interactive_svg_node_and_edge_search_metadata()`: verify shapes and edges contain node IDs, labels, and source/target IDs in interactive mode.
   - Verify non-interactive mode still produces byte-identical output without foreignObject or search metadata.

3. **Documentation (`docs/CAPABILITIES.md`, `docs/capabilities.json`, `docs/CHANGELOG.md`)**:
   - Update `CAP-DIAG-SEARCH` capability status and documentation.
