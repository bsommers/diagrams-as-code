<context>
Phase 10 delivers obstacle collision detection and deflection for curved edges. The mathematical foundation requires:
1. **De Casteljau Curve Subdivision (`CubicBezier.subdivide` / `CubicBezier.split`):** Evaluates recursive convex hull bisection at parameter $t \in [0.0, 1.0]$ (default $t=0.5$), dividing a cubic curve into two sub-curves with identical tangent directions at the split point (D-01).
2. **Two-Tier Collision Math (`CubicBezier.intersects_rect`):**
   - **Tier 1 (Broadphase Filter):** Evaluates `not self.bbox().intersects(rect)`. If the analytical tight bounding box does not intersect the target rectangle, reject in $O(1)$ without recursion (D-01).
   - **Tier 2 (Recursive Narrowphase):** If broadphase intersects, recursively bisect the curve via De Casteljau up to `max_depth = 4` ($2^4 = 16$ sub-segment bounding boxes, resolving curve position within $< 0.8\text{px}$). At each level, test the sub-curve control-net bounding box against the rectangle; prune non-intersecting branches; early-exit on the first intersecting leaf (D-01, D-04, T-10-01).
3. **Clearance Buffer Configuration (`Edge.clearance`):**
   - Add `clearance` parameter to `Edge.__init__`, defaulting to `15.0` pixels (matching `OrthogonalRouter` per D-02).
   - Add property getter and setter with strict float validation (`_validate_clearance`), rejecting negative numbers, non-numeric strings, booleans, NaN, and infinity.
   - Forward `clearance` through `_EdgeBuilder` and `Diagram.connect()` in `diagram.py`.
</context>

     - Guard `max_depth` to clamp at `max(1, min(max_depth, 8))` to prevent stack exhaustion (T-10-01).
     - Tier 1: if `not self.bbox().intersects(rect)`, return `False` immediately ($O(1)$ broadphase rejection per D-01).
     - Tier 2: define helper `_check_subcurve(curve: CubicBezier, depth: int) -> bool`:

       - AABB intersection check with `rect`:

       - If `depth >= max_depth`: return `True` (early-exit per D-04).
       - Recurse: `left, right = curve.subdivide(0.5)`. Return `_check_subcurve(left, depth + 1) or _check_subcurve(right, depth + 1)`.
