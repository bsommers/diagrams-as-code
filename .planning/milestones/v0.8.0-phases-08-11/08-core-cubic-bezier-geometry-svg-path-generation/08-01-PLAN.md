<action>
Implement analytical bounding box and arc-length midpoint methods on `CubicBezier` in `src/diagrams_as_code/geometry.py`:
1. Implement `bbox(self) -> Rect`:
   - Compute tight axis-aligned bounding box from analytical quadratic roots of first derivative:
     - For $x$: $B'_x(t) = a_x t^2 + b_x t + c_x = 0$ where:
       $a_x = 3(-p0.x + 3 c1.x - 3 c2.x + p3.x)$
       $b_x = 6(p0.x - 2 c1.x + c2.x)$
       $c_x = 3(c1.x - p0.x)$
     - For $y$: $B'_y(t) = a_y t^2 + b_y t + c_y = 0$ analogously.
   - Helper `solve_quadratic(a, b, c) -> list[float]`: handle linear case ($|a| < 10^{-9}$), negative discriminant, and real roots.
   - Evaluate $B(t)$ at candidate set $\{0.0, 1.0\} \cup \{t \in (0, 1) \mid B'_x(t) = 0 \text{ or } B'_y(t) = 0\}$.
   - Return `Rect(min_x, min_y, max_x - min_x, max_y - min_y)`.
2. Implement `arc_length(self, num_samples: int = 32) -> float`:
   - Compute cumulative Euclidean chord distance across `self.sample(num_samples + 1)` using `math.hypot`.
3. Implement `arc_length_midpoint(self, num_samples: int = 32) -> Point`:
   - Per decision D-09, divide curve into `num_samples` chords (default 32).
   - Build cumulative distance array `dists = [0.0, d_1, d_1+d_2, ..., L]`.
   - If total length $L < 10^{-6}$, return `self.p0`.
   - Use `bisect.bisect_right(dists, L / 2.0) - 1` to find segment index `idx`.
   - Linearly interpolate fractional offset $\alpha$ within chord `idx` to find $t_{\text{mid}} = (idx + \alpha) / num\_samples$.
   - Return `self.point_at(t_{\text{mid}})`.
</action>
