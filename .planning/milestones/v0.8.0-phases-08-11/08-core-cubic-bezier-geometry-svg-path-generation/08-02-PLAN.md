<context>
In Phase 8, when an `Edge` is configured with `routing=Routing.CURVE` (or `"curve"`), Layer 3 calculates the control points $C_1$ and $C_2$ between $P_{\text{start}}$ and $P_{\text{end}}$. 

Per user decisions D-01 through D-08, D-13, and D-15:
- Waypoints contract: exactly 4 points `[P_start, C_1, C_2, P_end]` are stored in `edge.waypoints` (D-13).
- Strict port tangency: handles project along outward normal rays: $C_1 = P_0 + d_1 \vec{n}_{\text{src}}$ and $C_2 = P_3 + d_2 \vec{n}_{\text{tgt}}$ (BEZ-02).
- Proportional scaling along primary flow axis: $d = \max(0.5 \cdot \Delta_{\text{axis}}, 25.0)$ with no upper clamp (D-01, D-02).
- Lateral blend: $d = \max(0.5 \cdot \Delta_{\text{axis}}, 0.25 \cdot |\Delta_{\text{lateral}}|, 20.0)$ to prevent steep sharp bends (D-03).
- Perpendicular ports: scale handles independently by axis delta $d_1 = \max(0.5 \cdot |\Delta x|, 25.0), d_2 = \max(0.5 \cdot |\Delta y|, 25.0)$ (D-05).
- Parallel / same-side ports: outward projection with clearance proportional to separation $d = \max(0.5 \cdot |\Delta_{\text{sep}}|, 30.0)$ (D-06).
- Backward / reverse-facing flow: outward normal projection with minimum clearance offset of 30.0px (D-07).
- Automatic port resolution: reuse existing bounding box spatial orientation logic from `OrthogonalRouter.resolve_ports` when ports are not explicitly specified (D-08).
- Minimum handle length invariant: $\|P_3 - C_2\| \ge 20.0\text{px} \ge 1.0\text{px}$ prevents degenerate zero-tangent marker rotation in SVG (D-02, D-15, T-08-01).
</context>
