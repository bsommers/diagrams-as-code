<context>
Layer 4 receives routed edges whose `waypoints` contain clean Manhattan corner sequences `[P_0, P_1, ..., P_n]`. Per user decisions D-05 through D-16:
- Waypoints Contract: `Edge.waypoints` is never corrupted with fillet sub-points or curves; it remains the clean Manhattan corner polyline (D-11).
- Quadratic Bezier Geometry: At each 90-degree corner vertex $P_c$, setting control point $P_1 = P_c$ guarantees exact $C^1$ tangent continuity along incoming unit vector $\mathbf{u}_{\text{in}}$ and outgoing unit vector $\mathbf{u}_{\text{out}}$: $T_1 = P_c - \mathbf{u}_{\text{in}} R_{\text{eff}}$ and $T_2 = P_c + \mathbf{u}_{\text{out}} R_{\text{eff}}$ (D-09, FILLET-03).
- Dynamic 50% Budget Clamping: $R_{\text{eff}} \le \min(R, L_{\text{in}} / 2, L_{\text{out}} / 2)$ prevents adjacent corner arcs on short segments from crossing over into "dog ear" loops (D-05, FILLET-02).
- Lead-in Straightness: Reserving at least $\min(10.0, L / 2)$ on segments entering or exiting ports keeps arrowheads seating flush and perpendicular against shape bounds without angled tilt (D-08).
- Threshold Suppression: Clamping $R_{\text{eff}} < 2.0\text{px}$ to sharp right angles suppresses sub-pixel rasterization artifacts (D-06).
- Obstacle Apex Clearance: Rounding inside an obstacle corner must not penetrate the obstacle; inside apex $P_{\text{apex}} = P_c - 0.25 R (\mathbf{u}_{\text{in}} - \mathbf{u}_{\text{out}})$ is clamped to keep $\ge 4.0\text{px}$ clearance from obstacle bounding boxes (D-14).
- Protocol Badge Centering: Badges are placed on the midpoint of the longest straight segment, keeping labels on flat lines rather than straddling corner bends (D-12).
</context>

       `f"M {pts[0].x} {pts[0].y} " + " ".join(f"L {p.x} {p.y}" for p in pts[1:])` (D-02).
     - Precalculate segment lengths and unit vectors for each segment $j \in [0, n - 2]$:
       $v_x = P_{j+1}.x - P_j.x$, $v_y = P_{j+1}.y - P_j.y$, $L = \text{math.hypot}(v_x, v_y)$.
       Unit vector $\mathbf{u} = \text{Point}(v_x / L, v_y / L)$ if $L > 10^{-6}$ else $\text{Point}(0.0, 0.0)$ (T-09-04).
     - Initialize `effective_radii = [0.0] * n`.
     - For each interior corner $i \in [1, n - 2]$:
       - $L_{\text{in}} = \text{seg\_lens}[i - 1]$, $L_{\text{out}} = \text{seg\_lens}[i]$.
       - If $L_{\text{in}} < 10^{-6}$ or $L_{\text{out}} < 10^{-6}$, continue (leave sharp).
       - Orthogonal turn check (D-07): dot product $\mathbf{u}_{\text{in}} \cdot \mathbf{u}_{\text{out}} = u_{\text{in}}.x \cdot u_{\text{out}}.x + u_{\text{in}}.y \cdot u_{\text{out}}.y$.
         If $|\mathbf{u}_{\text{in}} \cdot \mathbf{u}_{\text{out}}| > 10^{-6}$, continue (collinear or turnaround; leave sharp).
       - 50% segment budget (D-05):
         $\text{max\_r\_in} = L_{\text{in}} / 2.0$, $\text{max\_r\_out} = L_{\text{out}} / 2.0$.
       - Port straight lead-in enforcement (D-08):
         If $i == 1$: $\text{lead\_in} = \min(10.0, L_{\text{in}} / 2.0)$; $\text{max\_r\_in} = \min(\text{max\_r\_in}, \max(0.0, L_{\text{in}} - \text{lead\_in}))$.
         If $i == n - 2$: $\text{lead\_in} = \min(10.0, L_{\text{out}} / 2.0)$; $\text{max\_r\_out} = \min(\text{max\_r\_out}, \max(0.0, L_{\text{out}} - \text{lead\_in}))$.
       - Initial clamped radius: $r_{\text{corner}} = \min(corner\_radius, \text{max\_r\_in}, \text{max\_r\_out})$.
       - Obstacle clearance guard (D-14, T-09-06):
         If `obstacles` is provided and $r_{\text{corner}} \ge 2.0$:
           $P_c = pts[i]$.
           Inside apex displacement vector: $dx_{\text{apex}} = -0.25 \cdot (u_{\text{in}}.x - u_{\text{out}}.x)$, $dy_{\text{apex}} = -0.25 \cdot (u_{\text{in}}.y - u_{\text{out}}.y)$.
           For each obstacle $obs \in \text{obstacles}$:
             $exp = obs.\text{expand}(4.0)$.
             $\text{apex\_x} = P_c.x + r_{\text{corner}} \cdot dx_{\text{apex}}$, $\text{apex\_y} = P_c.y + r_{\text{corner}} \cdot dy_{\text{apex}}$.
             If $exp.\text{left} < \text{apex\_x} < exp.\text{right}$ and $exp.\text{top} < \text{apex\_y} < exp.\text{bottom}$:
               $\text{safe\_r} = r_{\text{corner}}$.
               If $|dx_{\text{apex}}| > 10^{-6}$:
                 $\text{target\_x} = exp.\text{right}$ if $dx_{\text{apex}} < 0$ else $exp.\text{left}$.
                 $\text{safe\_r} = \min(\text{safe\_r}, \max(0.0, (\text{target\_x} - P_c.x) / dx_{\text{apex}}))$.
               If $|dy_{\text{apex}}| > 10^{-6}$:
                 $\text{target\_y} = exp.\text{bottom}$ if $dy_{\text{apex}} < 0$ else $exp.\text{top}$.
                 $\text{safe\_r} = \min(\text{safe\_r}, \max(0.0, (\text{target\_y} - P_c.y) / dy_{\text{apex}}))$.
               $r_{\text{corner}} = \min(r_{\text{corner}}, \text{safe\_r})$.
       - Minimum threshold suppression (D-06):
         If $r_{\text{corner}} < 2.0$: $r_{\text{corner}} = 0.0$.
       - Store `effective_radii[i] = r_corner`.
     - Assemble SVG path string (D-09):
       $parts = [f"M \{pts[0].x\} \{pts[0].y\}"]$.
       For $i \in [1, n - 2]$:
         $P_c = pts[i]$, $r = \text{effective\_radii}[i]$.
         If $r \ge 2.0$:
           $T_1 = \text{Point}(P_c.x - u_{\text{in}}.x \cdot r, P_c.y - u_{\text{in}}.y \cdot r)$.
           $T_2 = \text{Point}(P_c.x + u_{\text{out}}.x \cdot r, P_c.y + u_{\text{out}}.y \cdot r)$.
           $parts.\text{append}(f"L \{T_1.x\} \{T_1.y\} Q \{P_c.x\} \{P_c.y\}, \{T_2.x\} \{T_2.y\}").$
         Else:
           $parts.\text{append}(f"L \{P_c.x\} \{P_c.y\}").$
       $parts.\text{append}(f"L \{pts[-1].x\} \{pts[-1].y\}").$
       Return `" ".join(parts)`.
