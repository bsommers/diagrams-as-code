<action>
Implement `QuadraticBezier` in `src/diagrams_as_code/geometry.py` and unit tests in `tests/test_geometry.py`:
1. In `src/diagrams_as_code/geometry.py`:
   - Implement `@dataclass(frozen=True) class QuadraticBezier`:
     - Attributes: `p0: Point`, `p1: Point`, `p2: Point` (endpoints $p_0, p_2$ and control point $p_1$) (D-10).
     - `point_at(self, t: float) -> Point`:
       Evaluate Bernstein basis: $(1-t)^2 P_0 + 2(1-t)t P_1 + t^2 P_2$.
     - `tangent_at(self, t: float) -> Point`:
       Evaluate first derivative velocity vector $B'(t) = 2(1-t)(P_1 - P_0) + 2t(P_2 - P_1)$.
     - `sample(self, n: int = 16) -> list[Point]`:
       Uniform parameter sampling at $t = i / (n - 1)$ for $i \in [0, n - 1]$. If $n < 2$, return `[self.p0, self.p2]`.
     - `bbox(self) -> Rect`:
       Compute exact tight axis-aligned bounding box from analytical linear roots of first derivative:
       - For $x$: $B'_x(t) = 2(1-t)(p1.x - p0.x) + 2t(p2.x - p1.x) = 0 \implies t \cdot (p0.x - 2 p1.x + p2.x) = p0.x - p1.x$.
         If $|p0.x - 2 p1.x + p2.x| > 10^{-9}$, test candidate $t_x = (p0.x - p1.x) / (p0.x - 2 p1.x + p2.x)$. If $0 < t_x < 1$, evaluate $B(t_x)$.
       - For $y$: analogously for $t_y$.
       - Candidate parameter set: $\{0.0, 1.0\} \cup \{t \in (0, 1) \mid B'_x(t) = 0 \text{ or } B'_y(t) = 0\}$.
       - Return `Rect(min_x, min_y, max_x - min_x, max_y - min_y)`.
     - `arc_length(self, num_samples: int = 16) -> float`:
       Compute cumulative Euclidean chord distance across `self.sample(num_samples + 1)` using `distance_to`.
2. In `tests/test_geometry.py`:
   - Add `test_quadratic_bezier_evaluation_and_tangents()`: verify endpoints $t=0, 1$, midpoint $t=0.5$, and analytical derivative vectors $B'(0) = 2(P_1 - P_0)$ and $B'(1) = 2(P_2 - P_1)$.
   - Add `test_quadratic_bezier_bbox_vs_numerical_samples()`: verify analytical `bbox()` matches 1,001 numerical samples within $0.01$ tolerance on curves with extrema.
   - Add `test_quadratic_bezier_arc_length_and_immutability()`: test collinear points equal Euclidean length and verify mutating attributes raises `FrozenInstanceError`.
</action>
