<context>
Building upon the geometric collision detection in Plan 10-01, Layer 3 `CurveRouter` requires:
1. **Obstacle Normalization (D-03):** Edges must not consider their own source and target elements as obstacles. Container groups enclosing the source or target must also be excluded from collision testing to prevent false positives.
2. **Clearance-Inflated Collision Detection (D-01, D-02):** Before testing a candidate cubic curve, each obstacle bounding box is expanded by `edge.clearance` (default 15.0px). Tier 1 AABB broadphase filters non-colliding obstacles; Tier 2 De Casteljau subdivision confirms true collisions.
3. **Reverse-Flow Identification & Port Resolution (D-14, CURVEOBS-03):** When an edge flows backwards ($\Delta x < 0$ in horizontal diagrams or $\Delta y < 0$ in vertical diagrams) and ports are unspecified (`source_port is None and target_port is None`), resolving to facing ports (`EAST -> WEST`) forces the curve to slice through source and target node interiors. The router must automatically resolve to outward lateral cardinal ports (`NORTH -> NORTH` or `SOUTH -> SOUTH` based on available vertical clearance), creating a clean bypass loop.
4. **Lateral Escape Clearance Margin (D-13, D-15):** When reverse-flow edges have explicit facing ports, a single cubic Bezier crosses handles and creates a self-intersecting bow-tie loop (Pitfall 3). The router must project escape waypoints laterally beyond shape boundaries with a minimum clearance margin of $30.0\text{px}$, safely preventing loops and node clipping (T-10-04).
</context>

Implement automatic reverse-flow port resolution in `CurveRouter.resolve_ports` (`src/diagrams_as_code/router.py`):
1. In `CurveRouter.resolve_ports(self, edge: Edge, obstacles: Optional[list[Rect]] = None) -> tuple[Port, Port]`:
   - If both `edge.source_port` and `edge.target_port` are explicitly provided, return `(edge.source_port, edge.target_port)`.
   - Calculate delta between shape centers:
     `sb, tb = edge.source.bounds, edge.target.bounds`
     `dx = tb.center.x - sb.center.x`
     `dy = tb.center.y - sb.center.y`
   - If `abs(dx) >= abs(dy)` (horizontal layout dominant):
     - If `dx < 0` and `edge.source_port is None` and `edge.target_port is None`:
       - Reverse-flow horizontal detected! Resolve to outward lateral cardinal ports (D-14).
       - Evaluate clearance above vs below: compare `min(sb.top, tb.top)` clearance vs bottom clearance. Default to `(Port.NORTH, Port.NORTH)`. If NORTH is constrained by obstacles or canvas boundary ($y \le 30$), select `(Port.SOUTH, Port.SOUTH)`.
       - Return resolved lateral ports.
     - Otherwise forward flow: `src_p = Port.EAST if dx > 0 else Port.WEST`, `tgt_p = Port.WEST if dx > 0 else Port.EAST`.
   - Else (vertical layout dominant):
     - If `dy < 0` and `edge.source_port is None` and `edge.target_port is None`:
       - Reverse-flow vertical detected! Resolve to outward lateral cardinal ports `(Port.EAST, Port.EAST)` or `(Port.WEST, Port.WEST)` (D-14).
     - Otherwise forward flow: `src_p = Port.SOUTH if dy > 0 else Port.NORTH`, `tgt_p = Port.NORTH if dy > 0 else Port.SOUTH`.
   - Return `(edge.source_port or src_p, edge.target_port or tgt_p)`.

     - Verify vertical back-edge ($\Delta y = -200$) with unspecified ports resolves to `(Port.EAST, Port.EAST)`.
     - Verify forward edges ($\Delta x > 0$) continue to resolve to `(Port.EAST, Port.WEST)`.
