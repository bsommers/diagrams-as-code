<decisions_made>
Key Locked Decisions (D-01 through D-16 in `09-CONTEXT.md`):
- **D-01:** `corner_radius` primary with `arc_radius` alias on `Edge` and `Diagram`.
- **D-02:** Sharp corners by default (`corner_radius=0.0 / None`) for 100% backward compatibility.
- **D-03:** `corner_radius` applies strictly to `Routing.ORTHOGONAL` (gracefully ignored on DIRECT/CURVE).
- **D-04:** Coerce int/float to float; raise `ValueError` on negative values.
- **D-05:** Strict 50% segment budget per corner: $R_{\text{effective}} = \min(R, L_{\text{in}}/2, L_{\text{out}}/2)$.
- **D-06:** Suppress fillets if $R_{\text{effective}} < 2.0\text{px}$ (fallback to clean sharp 90-degree corner).
- **D-07:** Apply fillets strictly to 90-degree orthogonal turns where $\mathbf{u}_{\text{in}} \cdot \mathbf{u}_{\text{out}} = 0$.
- **D-08:** Enforce minimum straight lead-in of at least $10.0\text{px}$ at port anchors and arrowheads.
- **D-09:** Emit quadratic Bezier `L T1.x T1.y Q P_c.x P_c.y, T2.x T2.y` commands.
- **D-10:** Implement immutable `geometry.QuadraticBezier(p0, p1, p2)` in Layer 0.
- **D-11:** Keep `Edge.waypoints` as sharp Manhattan vertices; generate fillets in Layer 4 during SVG path emission.
- **D-12:** Keep existing orthogonal badge placement centered on the longest straight segment.
- **D-13:** Apply corner filleting uniformly across default and obstacle detour paths.
- **D-14:** Dynamic clearance guard clamps $R_{\text{effective}}$ so the fillet apex maintains $\ge 4.0\text{px}$ clearance from obstacles.
- **D-15:** $O(1)$ analytical vector math in pure Python standard library.
- **D-16:** Emit native standard SVG `<path>` elements for zero-code interactive pan/zoom and minimap compatibility.
