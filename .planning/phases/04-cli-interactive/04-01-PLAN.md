# Plan: Phase 4 Plan 04-01 (CLI Interactive Option)

**Phase:** Phase 4: CLI `--interactive` Option (`CAP-DIAG-CLI-INTERACTIVE`)  
**Requirements:** `CLI-INTER-01`, `CLI-INTER-02`, `CLI-INTER-03`, `CLI-INTER-04`  
**Goal:** Allow users to export interactive, pan/zoom-enabled SVG diagrams directly via the standalone CLI (`diagrams-as-code render`).

## Context & Architecture

- `Diagram` and `SVGRenderer` already support `interactive=True` (shipped in `v0.5.0`).
- `Diagram.configure()` accepts `interactive: Optional[bool] = None`.
- The CLI (`src/diagrams_as_code/cli.py`) currently forwards `layout`, `direction`, `layout_file`, and `theme` in `_configure()`, but does not yet expose an `--interactive` argument flag.

## Proposed Changes

1. **CLI Parser (`src/diagrams_as_code/cli.py`)**:
   - In `build_parser()`, add `--interactive` (and `--no-interactive`) flags to the `render` subparser:
     ```python
     render.add_argument(
         "--interactive",
         dest="interactive",
         action="store_true",
         default=None,
         help="emit interactive pan/zoom-enabled SVG output",
     )
     render.add_argument(
         "--no-interactive",
         dest="interactive",
         action="store_false",
         help="disable interactive SVG output",
     )
     ```
   - In `_configure(diag: Diagram, args: argparse.Namespace, theme: Optional[str] = None)`:
     Pass `interactive=getattr(args, "interactive", None)` to `diag.configure(...)`.

2. **Integration Tests (`tests/test_cli.py`)**:
   - Add `test_cli_render_interactive_flag(tmp_path)`: verify `--interactive` flag causes rendered SVGs to contain `#svg-pan-zoom-controls` and `diagram-interactive`.
   - Add `test_cli_render_no_interactive_flag(tmp_path)`: verify `--no-interactive` overrides script-level `interactive=True`.
   - Add `test_cli_render_interactive_batch(tmp_path)`: verify batch directory rendering applies `--interactive` across all discovered scripts.
   - Add `test_cli_help_lists_interactive()`: verify `diagrams-as-code render --help` lists `--interactive`.

3. **Documentation (`docs/CAPABILITIES.md`, `docs/capabilities.json`)**:
   - Update `CAP-DIAG-CLI-INTERACTIVE` status from `PLANNED` to `OPERATIONAL`.
